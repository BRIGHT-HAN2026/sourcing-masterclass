## 4. 섹션 구성 (순서대로)

### S1. Hero
- 배경: 풀스크린 다크 + 골드 그라디언트 오버레이
- 헤드라인: "6개 브랜드를 직접 운영하는 대표에게 배우는\n중국 소싱부터 자사몰 판매까지"
- 서브: "소싱브랜딩 마스터클래스 — 8주 라이브 코칭"
- CTA 버튼: "수강 신청하기" (골드 버튼, 결제 섹션으로 앵커)
- 하단: 브랜드 6개 이름 나열 (신뢰 배지)

### S2. Pain Points (공감 섹션)
- 타이틀: "이런 고민, 있으시죠?"
- 3가지 카드:
  1. 중국 소싱 어디서 어떻게 시작해야 할지 막막하다
  2. 광고를 만들어도 클릭이 없고 매출이 안 난다
  3. 자사몰을 열고 싶은데 전체 흐름을 아는 사람이 없다

### S3. 강사 소개
- 한봉석 대표 이름 + 직함
- 운영 브랜드 6개 로고/이름 그리드
- 짧은 소개문: "직접 소싱하고, 직접 광고 만들고, 직접 판매합니다. 지금 이 순간도 운영 중인 6개 브랜드가 그 증거입니다."

### S4. 이 강의가 다른 이유
- 3개 차별점 카드:
  1. **현직 운영자** — 이론 없이 실제 운영 중인 프로세스 공개
  2. **라이브 코칭** — 녹화 강의가 아닌 실시간 질의응답
  3. **전 공정 커버** — 소싱→검수→상세페이지→광고→판매 한 번에

### S5. 커리큘럼 (8회차)
타임라인 또는 아코디언 형태:

| 회차 | 주제 |
|------|------|
| 1회차 | 자사몰 비즈니스 구조 이해 + 성공 제품 기준 잡기 |
| 2회차 | 중국 플랫폼(1688·알리바바·핀둬둬) 탐색 & 계정 세팅 |
| 3회차 | 제품 선정 기준 & 시장 조사 (경쟁사·가격·마진 분석) |
| 4회차 | 샘플 발주 → 검수 → 통관 실전 프로세스 |
| 5회차 | 자사몰 구축 + 상세페이지 제작 (전환율 높이는 구조) |
| 6회차 | 광고 소재 제작 (카피·이미지·영상 기획) |
| 7회차 | 네이버·메타 광고 세팅 & 예산 운영 실전 |
| 8회차 | 데이터 분석 → 재소싱 → 스케일업 전략 |
