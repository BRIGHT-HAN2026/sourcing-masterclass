# 소싱브랜딩 마스터클래스 랜딩페이지 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소싱브랜딩 마스터클래스 라이브 코칭 강의의 단일 HTML 랜딩페이지 제작 (10개 섹션 + 포트원 자체 결제 포함)

**Architecture:** 순수 HTML/CSS/JS 3-파일 구조. 외부 의존성은 Pretendard 폰트 CDN과 포트원 V1 SDK만. 섹션별로 CSS 추가, Task 7에서 JS 상호작용 일괄 완성, Task 8에서 결제 + 모바일 반응형 마무리.

**Tech Stack:** HTML5, CSS3 (CSS Custom Properties), Vanilla JS (ES6+), 포트원(iamport) V1 SDK, Pretendard CDN (jsdelivr)

## Global Constraints

- 폰트: `'Pretendard'` — `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css`

- 강사: `한봉석 대표`
- 운영 브랜드 6개 (순서 고정): 만듬, 유르테, 플뤼에, 오울트리, 큐오큐오, 노노트
- 가격 placeholder: `[가격 TBD]`
